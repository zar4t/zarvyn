# Security Policy

Zarvyn is in its security design phase; no production code has been released yet.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting:
https://github.com/zar4t/zarvyn/security/advisories/new

Do not open public issues for security problems. Never include real credentials
or secrets; use synthetic reproductions. You can expect a first response within
7 days.

## Responsible publication

Zarvyn documents attacks in order to prove defenses. This repository follows
three rules:

1. Attack material here targets the Zarvyn lab only and is limited to what is
   needed to prove that a control works.
2. Write-ups describe the class of issue, its impact, the fix and the detection.
   They do not provide step-by-step instructions that work against other systems.
3. Vulnerabilities found in third-party software stay private until the vendor
   has released a fix, following coordinated disclosure.

## Responsible use

Use any test or tool from this project only on systems you own or are explicitly
authorized to test.
